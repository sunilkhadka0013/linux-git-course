Linux

What is Linux?

  • An open-source operating system kernel, created by Linus Torvalds in 1991
  • A distribution (distro) bundles the kernel with tools, a desktop and a package manager
  • Free to use, inspect, modify and share
  • Built around the command line: small tools that do one thing well

Linux

Everything is a file

# one tree, starting at /
/
├── home/    # your files
├── etc/     # configuration
├── var/     # logs, changing data
├── usr/     # installed programs
├── bin/     # essential commands
├── tmp/     # temporary files
└── dev/     # devices as files
  • No drive letters, just one tree
  • ~ is your home folder
  • Paths are case-sensitive

Linux

Commands to learn first

$ pwd                  # where am I?
$ ls -la               # list files, including hidden
$ cd projects          # move into a folder
$ mkdir notes          # create a folder
$ touch todo.txt       # create an empty file
$ cp a.txt b.txt       # copy
$ mv b.txt docs/       # move or rename
$ rm todo.txt         # delete (no recycle bin!)
$ man ls              # read the manual

Git

What is Git?

  • A free tool that you install on your computer
  • It remembers every change you make to your code
  • Like save points in a game: if you break something, go back
  • We use Git to send our code from our device to GitHub

Git

Your first repository

$ git init                         # start tracking this folder
$ git status                       # what changed?
$ git add index.html               # stage a file
$ git commit -m "Add home page"    # save a snapshot
$ git log --oneline                # view history
$ git remote add origin <url>      # connect to GitHub
$ git push -u origin main          # upload
